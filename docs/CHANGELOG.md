# 更新日志

> 每个版本的功能日志。约定：随发版一起更新，条目面向用户（写成"能做什么"而非"改了什么文件"）；
> 提交信息里的 feat/fix 已足够归档，这里挑对用户可见有感知的写。
> 版本号与日期以 git tag 为准，各版本完整提交记录见 GitHub Releases。

## 0.4.0 — 2026-10-20

- 检查更新功能：启动后静默检查一次新版本，右下角浮动提示条可一键下载（带进度）并重启安装；全局设置新增「关于」区块可手动检查。对应 GitHub Releases 自动更新链路（`docs/RELEASE.md`）。

## 0.3.1 — 2026-10-20

- JSON 树视图：折叠占位显示「… N 项」，一眼知道折叠区有多少内容（Apifox 式折叠计数）
- 修复：JSON 比对空输入不再误报「输出过大，已用文本视图」
- 修复：原生标题栏恢复跟随主题（补主题与窗口背景色权限）

## 0.3.0 — 2026-10-18

- JSON 输出区树视图：格式化 / 提取 / 比对三工具接入结构化查看，超出体积阈值自动回落文本视图
- 一批横切便捷能力：文件载入、发送到、会话历史、文本操作、收藏
- Tab 右键菜单：一键关闭全部标签页
- 修复：错误行号不再依赖引擎报错文案，三处 JSON 工具共用位置感知扫描，行号全工具可点击跳转
- 修复：侧栏加宽到 160，工具名不再被截断

## 0.2.3 — 2026-10-17

- 性能整改：正则 Worker 生命周期修复（卸载泄漏 / 过期请求残留）、JSON 比对保活、重计算防抖

## 0.2.2 — 2026-10-04

- 修复：屏蔽 WebView 自带右键菜单，避免应用内弹出浏览器菜单项

## 0.2.1 — 2026-10-03

- 修复：应用图标按 macOS 网格缩至 824/1024，Dock 中不再偏大突兀

## 0.2.0 — 2026-10-03

- 新增 JSON 比对、JSON 提取工具；数据集格式化过度膨胀后合并 0.2.0
- 视觉升级：分层表面、五档字号 token、输出区搜索、原生窗口随主题切换
- JSON 格式化新增「去转义」：转义的 JSON 文档自动反转义后格式化（默认开启）
- 全局设置：外观三选一（深色 / 浅色 / 跟随系统）+ 工作区布局方向（上下 / 左右分栏）
- 全局密度收紧：紧凑侧栏 / 面板 / 编辑器，适配笔记本小屏
- 品牌图标重设计（蓝底白符），浅色主题去蓝提层次

## 0.1.0 — 2026-10-02

- 首个可用版本：八个工具（JSON 格式化、Base64、URL 编解码、时间戳、UUID、哈希、JWT 解码、正则测试）
- Tauri 2 桌面壳，macOS + Windows 出包；⌘W 关标签页、退出确认等桌面体验打磨
