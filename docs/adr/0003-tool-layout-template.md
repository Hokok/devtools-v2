# 工具界面统一 Input/Output 模板，特殊工具可整体覆盖

为保证几十个工具的交互一致性并让"加一个工具"尽量只写转换逻辑，平台提供默认工具布局模板：输入区 → 处理 → 输出区，附带统一的工具栏与选项注入点（设置面板由此获得统一的数据来源）。正则测试器、取色器等无法套用三段式的工具，允许在 ToolDefinition 中整体覆盖布局——但覆盖必须以整个布局为单位，不允许零散偏离模板。

## Consequences

- ToolDefinition 的布局 API 是全应用最核心的扩展点，升级需向后兼容所有存量工具。
- 评审新工具时以"是否可以不覆盖布局"为默认立场；覆盖布局需要说明理由。
